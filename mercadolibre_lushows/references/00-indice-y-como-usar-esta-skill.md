# Índice y cómo usar esta skill

200 módulos. **Nunca los leas todos**: carga de 1 a 5 según la pregunta. Este archivo es el mapa
para encontrar el correcto rápido.

## Los cuatro atajos que resuelven el 80% de las consultas

| Si el usuario dice... | Abre primero |
|---|---|
| "quiero empezar a vender en ML" | `04` diagnóstico → `174` hoja de ruta de 90 días |
| "no aparezco / me caí en el buscador" | `72` por qué cayó mi publicación |
| "no me da el margen / cuánto me queda" | `82` calculadora → ejecuta `scripts/margen_ml.py` |
| "me bajó la reputación / me suspendieron" | `144` plan de defensa de la cuenta |

Esos cuatro (`04`, `72`, `82`, `144`) son herramientas autónomas: funcionan solos, sin cargar el
resto del bloque. Igual que `54` (auditoría de una publicación) y `124` (auditoría logística).

## El orden que no se salta

```
1. ¿SOBREVIVE?   margen tras comisión + envío + IVA      75-99
2. ¿SE ENTIENDE? categoría, título, ficha, fotos         25-54
3. ¿LLEGA?       logística y promesa de entrega          100-124
4. ¿SE VE?       algoritmo, catálogo y al final la pauta 55-74, 145-164
```

Pautar (4) un producto que no sobrevive (1) es la forma más rápida de perder plata aquí. Ver `154`.

## La herramienta ejecutable

```bash
python scripts/margen_ml.py margen --precio 89900 --costo 42000 --comision 14.5 --iva 19
python scripts/margen_ml.py minimo --costo 42000 --margen-objetivo 25 --comision 14.5 --iva 19
python scripts/margen_ml.py test      # verifica su propia aritmética
```

La comisión es un **parámetro que trae el usuario**, no un dato que el script sepa. Ver `76`.

## La regla que atraviesa los 200 módulos

Mercado Libre bloquea el acceso automatizado a sus páginas y la web está llena de cifras de
Argentina y México presentadas como colombianas. Por eso cada dato de esta skill lleva marca de
origen, y lo que no se pudo verificar **está declarado como no verificado** en vez de rellenado.

**Si una cifra no dice de qué país y de cuándo es, no sirve para decidir un precio.**
